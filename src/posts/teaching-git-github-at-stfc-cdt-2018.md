# Teaching git &amp; GitHub at STFC CDT 2018

Today, I visited the University of Edinburgh’s snazzy new Bayes Centre, as an invited speaker at the [STFC’s National CDT Meeting](https://www.scotdist.ac.uk/national-cdt-meeting). It was a real pleasure to teach the next generation of PhD students in data-intensive science the fundamentals of version control, git and GitHub/Bitbucket.
The two workshops I ran went pretty smoothly, and it seems like the 25 or so PhD students I taught have grasped the key points well. These skills will help them carry out their research projects more efficiently, with better reproducibility.  I know from my own experience that once git was part of my arsenal, my productivity massively increased.
I wish I could have attended an event like this when I was a first year PhD student. The event’s [workshops](https://www.scotdist.ac.uk/sites/default/files/atoms/files/national_meeting_parallel_programme_0.pdf) are covering an amazing breadth of material, from machine learning and GPU programming to code profiling, containerisation and cloud computing. If I’d picked up even a fraction of this knowledge at the beginning of my PhD, who knows how my thesis work might have been improved.
Sadly, I couldn’t stay for the afternoon’s career event, which also looked really interesting. A lot of my old colleagues are now in various industries, and it would have been great to catch up.
I hope that they release the slides from the other workshops - it’d be great to see what everyone else is learning about! If not, you can see my slides (PDF) [here](https://duncanforgan.wordpress.com/wp-content/uploads/2018/11/versioncontrol.pdf "versioncontrol").
